# Bavaria Lounge

Сайт Bavaria Cocktail Lounge / Shisha Bar у Хільдесгаймі.

Опублікований сайт: https://bavaria.sabsus.site/de/

## Можливості

- Німецька й англійська мови.
- Золотий логотип і безперервні градієнтні переливи.
- Скляні картки, фіксована шапка, мобільне меню.
- Анімація диму, заставка та поява контенту під час прокручування.
- Безперервна автоматична галерея.

## Запуск локально

Потрібен Python 3; npm і встановлення залежностей не потрібні.

```sh
python3 -m http.server 8000
```

Відкрий http://localhost:8000 у браузері.

## Структура

- `index.html` — сторінка для локального запуску.
- `pages/index.html` — шаблон сторінки для SABSUS.
- `assets/` — CSS, JavaScript, фотографії та логотип.
- `site.json`, `templates/` — контракт SABSUS.
- `integration/instagram-worker.mjs` — необов’язковий серверний адаптер; не розгорнутий.

## Перевірки

Потрібен Node.js із підтримкою `node:assert/strict`.

```sh
node --check assets/app.js
node --check assets/motion.js
node checks/motion.test.cjs
```

## Підготовка архіву

```sh
python3 build-preview.py
```

Створюються `sabsus-source.zip` для SABSUS та автономний HTML і повний ZIP у `deliverables/`. Згенеровані архіви не зберігаються в Git. Після зміни `pages/index.html` цей скрипт також оновлює локальний `index.html`.

## Поточні обмеження

Форма резервації демонстраційна: нічого не відправляє. Email і WhatsApp закладу — заглушки. Live Instagram не підключений; використані надані фотографії. Позиції та ціни меню — приклади. Повна візуальна перевірка у браузері не виконана; перед публікацією пройдено збірку й Release Guard SABSUS.

Фотографії закладу надані замовником; логотип і hero створені для цього проєкту. Репозиторій не надає окремої ліцензії на повторне використання цих матеріалів.
