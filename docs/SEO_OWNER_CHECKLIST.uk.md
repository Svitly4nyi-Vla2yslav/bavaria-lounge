# Короткий SEO-checklist власника Bavaria Lounge

## До публікації

- [ ] Підтвердити точні години закриття за кожен день.
- [ ] Підтвердити адресу, телефон, Google Maps, Instagram і Facebook.
- [ ] Надати перевірені Impressum і Datenschutzerklärung.
- [ ] Схвалити merge/deploy у Netlify; Firebase не вмикати.

## Після публікації

- [ ] Перевірити новий title/H1 і відсутність Halloween-події у View Source.
- [ ] Перевірити `robots.txt`, `sitemap.xml`, canonical і JSON-LD.
- [ ] Зробити тестове бронювання та перевірити Telegram.
- [ ] Завершити verification `bavaria-lounge.de` у Search Console.
- [ ] URL Inspection → Test live URL → Request indexing.
- [ ] Подати `https://bavaria-lounge.de/sitemap.xml`.
- [ ] Створити/підтвердити Google Business Profile без дубля; узгодити NAP і години.
- [ ] Додати справжні фото закладу в Google Business Profile.
- [ ] Через 7–14 днів перевірити Page indexing, selected canonical і last crawl.
- [ ] Запустити PageSpeed Insights mobile/desktop.

## Analytics

- [ ] Не встановлювати GA4, доки немає Measurement ID, коректної згоди та оновленої Datenschutzerklärung.
- [ ] Після юридичного погодження додати GA4 через consent-aware конфігурацію й перевірити Realtime без фіктивних conversion events.
